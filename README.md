# NBA 2K17 Switcher / Launcher

Play NBA 2K17 on both **Revival** and **Back2Back** on the same PC without the two clients
overwriting each other's saves. One window, two tiles: click the server you want.

Both clients run the game as Steam app 480 and share one Steam save folder; each uploads whatever
is in it to its own cloud. This launcher parks one client's saves and puts the other's in place
before starting the client.

**Install:** download `NBA2K17-Switcher-v*.zip` from the [latest release](../../releases/latest),
unzip it somewhere permanent, run `Split.cmd` once if both clients still share one game folder,
then run `Install.cmd`. Full instructions, the manual steps and troubleshooting are in
[README.txt](README.txt).

The launcher checks this repository's releases on start and offers updates with one click.
